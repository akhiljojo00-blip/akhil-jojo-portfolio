## Features

- 7-theme color system with smooth transitions (Ivory/Graphite, Charcoal/Copper, Forest/Lime, Burgundy/Rose, Sand/Terracotta, Black/Silver, Warm Sunset)
- Custom trailing cursor with contextual labels
- Abstract interactive canvas background (particles + floating geometric forms + cursor parallax)
- Scroll reveal, parallax, and section transitions
- Fully responsive (desktop → mobile) with reduced-motion support
- Custom scroll-progress indicator

## Tech

- Semantic HTML
- Modern CSS (custom properties, grid, clamp, animations)
- Vanilla JavaScript (no frameworks, no build step)

## Run locally

```bash
# from the project folder
python3 -m http.server 5173
# open http://localhost:5173
```

No backend or build step required — it runs as static files.

## Deploy

Works on any static host: GitHub Pages, Netlify, Vercel, Cloudflare Pages, etc.
